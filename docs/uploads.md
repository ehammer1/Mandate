# Photos and documents

Residents and officials can add photos and documents wherever they write: petitions,
comments, agenda items and drafts, poll questions and evidence that a mandate was done.

## From a phone

- **📷 Take a photo**: opens the camera.
- **🖼 Photo or file**: the photo library, or Files for PDFs.
- **📄 Scan a document**: photograph each page. Pages are cleaned up (black text on white)
  and joined into one PDF when you tap **Done**.

Before anything leaves the phone, photos are shrunk and saved again, which removes hidden
data such as where the photo was taken. Only JPEG, PNG, WebP and PDF files up to 10 MB are
accepted.

## AI help

With **"AI reads it"** ticked, Claude reads each file and returns:

- the text in it (so scans are searchable);
- a two- or three-sentence summary;
- a description for people using screen readers (you can edit it);
- a warning if it shows private details (a stranger's face, a licence plate, an ID number,
  a home address, a signature...), so you can remove it before it becomes public.

What AI read is shown under each file, labelled "check the original".

## Who can add files

Members on the voter list, anonymously: the app makes a private proof that you are on the
list, tied to that exact file. Each member can add 10 files a day (`UPLOADS_PER_DAY`), and
the lowest voter list allowed is set with `UPLOAD_MIN_TIER` (0 all members, 1 ID-checked,
2 full voting rights). Nobody, including the service, learns who added a file.

## Proof that a file was not changed

Files are stored on IPFS, whose address is itself a fingerprint of the content. Each file's
SHA-256 fingerprint is also written into the published text on the blockchain. **"Check it
is unchanged"** downloads the file and compares it with that fingerprint.

## Setting it up (Render, mandate-identity)

1. Create a free account at pinata.cloud. Go to **API Keys**, **New Key**, give it the
   **pinFileToIPFS** and **unpin** permissions (or Admin), and copy the **JWT**.
2. In Render, **mandate-identity**, **Environment**, add `PINATA_JWT` with that JWT.
3. For AI help, add `ANTHROPIC_API_KEY` there too (console.anthropic.com, API Keys).
4. `UPLOAD_ADMIN_TOKEN` is generated by Render for takedowns.

## Taking a file down

Files are public, and the fingerprint stays on the record, but a harmful or private file can
stop being served:

```
curl -X POST https://<identity service>/upload/remove \
  -H "Authorization: Bearer <UPLOAD_ADMIN_TOKEN>" -H "Content-Type: application/json" \
  -d '{"cid":"<the file's IPFS ID>","reason":"private details"}'
```

It is unpinned and the app shows "A file here was taken down". To keep it hidden after the
service restarts, also add the ID to `UPLOAD_BLOCKLIST` (comma-separated). Copies other
people made elsewhere on IPFS cannot be recalled.
